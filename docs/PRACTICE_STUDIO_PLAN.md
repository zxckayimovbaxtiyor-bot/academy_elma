# Interactive Practice Studio — план работ

Исходная система: React/TypeScript/Vite, FastAPI/Pydantic/SQLAlchemy,
PostgreSQL, существующие `/admin/practice`, версии JSON `schema_version=1`,
серверный интерпретатор, три режима прохождения и общий `ScenarioScreen`.

Сохраняем существующие таблицы сценариев, идентификаторы, маршруты и опубликованные
версии. Новые настройки формата получают значения по умолчанию. Активная попытка
продолжает работать с закреплённой версией. Старые сценарии входят в регрессионные
тесты и открываются новым редактором без ручной конвертации.

Порядок реализации:

1. Расширение типизированного формата: метаданные, свойства компонентов,
   ограниченные события/действия/условия, варианты и переменные. Неполный черновик
   можно сохранить; полная проверка обязательна перед предпросмотром и публикацией.
2. Существующие API: проверка урока, архив/восстановление, дублирование,
   библиотека шаблонов, защищённые учебные материалы и загрузки. Изменения БД —
   отдельной миграцией после `0004`.
3. Серверный движок: обработка событий, видимости, проверок, баллов и подсказок;
   ограничение автоматических переходов; проверка файлов и экзамена на сервере.
4. Замена длинной формы текущего конструктора рабочим пространством: библиотека
   и экраны, холст, инспектор; drag-and-drop, история изменений, автосохранение,
   карта переходов, проверка и публикация.
5. Общий интерфейс прохождения для сотрудника, холста и предпросмотра; выбор
   языка и варианта в предпросмотре без записи статистики.
6. Аналитика и документация. Автоматический полный цикл кредитного урока через
   HTTP API с PostgreSQL, тесты совместимости, прав, компонентов, правил,
   публикации и работы редактора. Проверка UI в браузере.

В правилах нет исполнения выражений или внешних банковских интеграций. Данные
проверки и условия остаются на сервере; ученик получает только текущий экран и
разрешённые учебные данные.
