# Практика: аудит и технический план

## Подтверждённая архитектура

Исходная рабочая папка содержала только ZIP и .git. Отсутствующие отслеживаемые
файлы восстановлены из HEAD 81817c9 через git archive, без изменения индекса.
Архив пользователя сохранён. Действующие данные БД в папке отсутствовали.

Проверены README, PLAN, MODERNIZATION, Compose, модели, маршруты, службы доступа,
оценивания, сертификатов, публикаций и отчётов, auth, Alembic, тестовые фикстуры,
локальный запуск и структура React. FastAPI использует синхронные SQLAlchemy
сессии: каждый маршрут явно фиксирует транзакцию. PostgreSQL 16, JSONB,
блокировки строк, Alembic 0001. Redis отсутствует. Worker выполняет фоновые задачи.

Роли: admin, methodologist, branch_head, learner. require_roles разрешает admin;
current_user проверяет сессию и обязательную смену пароля. Изменяющие запросы
защищены X-Requested-With. PrivateResponseMiddleware запрещает кэширование.
Назначения: филиал → волна → должность × модуль; общий Core открывает продукты
после сертификата. Правила доступа повторно проверяются на сервере.

Урокы имеют версии в ElmaRelease; публикация выпуска заменяет версии,
снимает вопросы старых версий и запускает повторную сертификацию затронутых
модулей. Тесты собираются и оцениваются сервером. Сертификаты имеют снимок
данных и выдаются после теста, а операторский сертификат — по всем назначениям.
Существующие сертификаты сохраняют прежние правила статуса.

React/TypeScript/Vite, react-router-dom, i18next/react-i18next. Админский bundle
загружается лениво. Brand, Feedback, кнопки, карточки, CSS tokens и Inter
переиспользуются. Словари RU/UZ проверяются скриптом при сборке. Новая UI
библиотека не требуется. Отчёты branch_head ограничены своим branch_id.

## Решение и последовательность

1. Добавить отдельные таблицы practice_scenario, practice_scenario_version,
   practice_session, practice_action, practice_result, practice_assignment.
   PracticeScreen и PracticeRule — типизированные вложенные структуры версии
   JSONB: отдельные таблицы дублировали бы канонический документ.
2. Строгая Pydantic схема: RU/UZ, экраны, компоненты, переходы, ограниченные
   правила сравнения. Нет eval, исполняемого кода, произвольных URL и SQL.
3. Опубликованные версии неизменяемы (в том числе триггер PostgreSQL).
   Редактирование создаёт следующий черновик. Сессия хранит снимок политики.
4. Запуск под блокировкой пользователя; каждое действие под блокировкой сессии.
   request_id + хеш команды обеспечивают идемпотентность; revision защищает
   от устаревшего состояния. Результат вычисляет исключительно сервер.
5. API каталога, запуска/восстановления, действий/сохранения, завершения,
   конструктора, предпросмотра, публикации, назначений и аналитики.
6. Нейтральная банковская оболочка, декларативный React renderer, обучение,
   песочница и экзамен. В экзамене скрывать подсказки и правила проверки.
7. Визуальный конструктор без кода: экраны, поля, кнопки, переходы, критерии,
   предпросмотр, публикация. Двуязычный пример потребительского кредита.
8. Ссылки из модуля/урока. PracticeAssignment задаёт необязательную по умолчанию
   политику: барьер перед тестом или сертификатом, попытки, балл, повторы,
   повторное прохождение после версии сценария или материала. Старые сертификаты
   не отзываются и не пересчитываются из-за новой практики.
9. Аналитика: попытки/результаты, ошибки/экраны, длительность, повторы,
   филиал/должность/сотрудник с серверным ограничением филиала.
10. Проверить миграции и регрессионные тесты на отдельной PostgreSQL *_test,
    TypeScript, i18n, frontend tests/build. Зафиксировать фактически выполненные
    проверки и ограничения в PRACTICE_IMPLEMENTATION.md.

## Изоляция

Только синтетические клиенты и учебные документы. Компонент документа выбирает
синтетический ресурс внутри сценария; файл сотрудника не отправляется.
Разрешённые скриншоты загружает методолог отдельным ограниченным endpoint:
только PNG/JPEG, ограничение размера, авторизация при чтении и проверка
принадлежности ресурса сценарию. React выводит строки как текст, HTML не
исполняется. Сценарии не имеют доступа к внешней сети.
