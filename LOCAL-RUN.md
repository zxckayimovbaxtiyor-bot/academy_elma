# Локальный запуск на Windows

Проект — корпоративная учебная платформа Yagona oyna Akademiyasi: курсы и видео,
тестирование, сертификаты, повторная сертификация после обновлений Elma365,
отчёты по филиалам и административная панель. Интерфейс доступен на узбекском
и русском языках. Стек: React + TypeScript + Vite, FastAPI + SQLAlchemy,
PostgreSQL 16, фоновый Python-обработчик, FFmpeg. Docker-развёртывание описано
в исходном README.md.

## Запуск подготовленной установки

Из папки проекта в PowerShell:

```powershell
.\start-local.ps1
```

Открыть <http://127.0.0.1:5173>. Панель: <http://127.0.0.1:5173/admin>.
Документация API: <http://127.0.0.1:5173/api/docs>.

Логины и временные пароли находятся в `.local/credentials.json`.
Администратор: `ADM-0001`. Демонстрационный ученик: `DEMO-0001`.
При первом входе требуется сменить временный пароль.
Файл содержит первоначальные временные пароли. После смены используйте пароль,
который вы задали: новый пароль не сохраняется в этом файле.
`synthetic_users` содержит общий пароль для синтетических сотрудников,
например `XB-100001`.

```powershell
.\stop-local.ps1
```

Остановка сохраняет базу и медиафайлы. Повторный запуск не создаёт новые аккаунты.
Процессы API и обработчика работают в фоне. Их журналы: `.local/*.log`.
PostgreSQL слушает только `127.0.0.1:54329`; приложение — `127.0.0.1:5173`.
Все данные этой установки лежат в `.local/`, которая исключена из Git.
Соединения PostgreSQL используют UTC; интерфейс показывает время Ташкента.

## Установка заново

Нужны Node.js и Python 3.12+:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-dev.txt
npm.cmd ci --prefix frontend
npm.cmd ci --prefix scripts/local-tools
npm.cmd run build --prefix frontend
.\.venv\Scripts\python.exe scripts\smoke-local.py
.\start-local.ps1 -Demo
```

`-Demo` добавляет 25 синтетических филиалов, 245 сотрудников, отдельного демоученика,
5 сгенерированных видеоуроков для Core и Farovon и 90 утверждённых тестовых вопросов.
Видео — тестовые изображения и звук; вопросы — арифметика. Реальных обучающих
материалов Elma365 в архиве нет. Генерация видео при первом запуске занимает время.

Локальный запуск использует переносимые инструменты из `scripts/local-tools`,
не устанавливает системные службы и не требует Docker. Python-сервер
`backend/local_server.py` раздаёт собранный интерфейс и медиа с проверкой входа;
промышленный вариант по-прежнему использует nginx и `app.main`.
Для AI-генерации вопросов нужен отдельный ключ Anthropic; локальный запуск её отключает.

## Проверки

При запущенной локальной базе:

```powershell
.\.venv\Scripts\python.exe scripts\local.py test
npm.cmd run build --prefix frontend
```

Серверные тесты используют отдельную базу `academy_test`, не учебную базу `academy`.

## Исправления для Windows

- `frontend/scripts/check-i18n.mjs`: преобразование URL в путь через `fileURLToPath`.
- `tzdata`: база часовых поясов для Python на Windows.
- Добавлены локальный сервер, команды запуска/остановки и переносимые инструменты.

Исправления доступа к медиа и остальные изменения первого этапа описаны в
`docs/MODERNIZATION.md`.
